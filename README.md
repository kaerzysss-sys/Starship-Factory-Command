# Starship Factory Command

## About

Starship Factory Command is a desktop-style companion app for **Starship Factory v4.9b**.

It helps you manage your game data, including:
- flights
- ships and boosters
- production
- finances
- recurring payments and revenue
- satellites and constellations
- mission programs and contracts
- history and transactions

### Launching the application

1. On GitHub, click **Code → Download ZIP** to download the repository.
2. Extract the downloaded ZIP file.
3. Open the extracted folder.
4. Double-click:

**`Start Starship Factory Command.vbs`**

The application will open automatically in its own window.

**No installation is required.** You do not need Node.js, npm, Electron, or any other additional software.

If `.vbs` files are blocked on your system, you can alternatively run:

**`Start Starship Factory Command.bat`**

## Important

Keep all files in the same folder.

Do not move or delete `StarshipFactoryCommand.html`, because the launcher needs this file to start the application.

## Saves

Your game data is stored locally in the browser storage used by the application.

The application does not require an internet connection to run.

If you are moving the application to another computer, use the application's own save/export functionality if available. Simply copying the HTML file may not copy browser-stored save data.

## Language

The application starts in **English by default**.

You can change the language from inside the application if another language is available.
